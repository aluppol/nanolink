Shorten a link

Paste a long URL. Creation runs through a queue, and the short link appears here as soon as it is ready.

NanoLink never visits the address you submit; it only checks the format.

    How NanoLink works
    1. The API gateway checks your sign-in token and daily quota, queues the request and answers 202 Accepted right away.
    2. NATS JetStream keeps the task on disk, on a subject partitioned by user.
    3. The creator service pulls tasks in batches and writes the links to MongoDB.
    4. The notifier pushes each result to this page over Server-Sent Events.
    5. Opening a short link reaches the redirect service, which reads through a Valkey cache and falls back to MongoDB.
